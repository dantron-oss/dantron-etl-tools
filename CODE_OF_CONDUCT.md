# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. In short: be kind, be patient, assume good faith, and keep discussion about the work.
Harassment of any kind is not accepted.

To report a problem, contact the maintainers privately through the contact details on the
repository's GitHub page. Reports are kept confidential.
